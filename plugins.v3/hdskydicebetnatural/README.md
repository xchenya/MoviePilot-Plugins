# HDSky 空论坛掷骰子（拟人）· MoviePilot V3

此插件移植自 [Kuanghom/MoviePilot-Plugins · hdskydicebetnatural](https://github.com/Kuanghom/MoviePilot-Plugins/tree/main/plugins.v2/hdskydicebetnatural)，原作者 **Kuanghom**，上游 V2 版本 1.0.3。

- **当前版本**：2.6.0（MoviePilot V3 专用）
- **宿主要求**：MoviePilot >= 3.0.0
- **V3 适配维护**：xchenya，保留原作者署名和原插件类名 HdskyDiceBetNatural
- **状态**：仅静态与模拟环境测试，尚未进行真实 HDSky 账号登录、下注或开奖联调

## 功能

保留上游 V2 原有能力：

- 固定、随机、智能与倍投四种下注模式；可分别配置大、小、顺子、豹子的金额与加注策略。
- 扫描 HDSky 论坛掷骰主题，读取开奖历史、识别锁定帖和本人已有下注。
- 模拟人工的扫描抖动、进帖停顿、开奖时间窗、随机跳过、金额微抖及假浏览。
- 每日下注次数、观影券次数及当日止盈/止损保护。
- 当日/本周/本月/累计盈亏、待结算记录、当前魔力及消息通知。
- 自动处理论坛评分短讯；保留上游可配置的短讯归档间隔。
- MoviePilot 原生 Cron 调度，以及配置保存后仅运行一次。

## 安装与配置

在 MoviePilot V3 的第三方插件市场中添加或保留：

https://github.com/xchenya/MoviePilot-Plugins

刷新插件列表，安装「空论坛掷骰子（拟人）」，选择站点管理中的 HDSky（hdsky.me）。主站 Cookie、User-Agent 与代理选项从站点管理读取；若使用辅助奖励来源，可在配置页「Emby 订阅登录」区域直接输入 UID、主站邮箱和站内信验证码登录，无需手动复制 Token。

**首次安装建议先不开启自动下注。** 先确认已正确选择站点、Cron、下注策略、魔力余额和每日次数上限。建议设置当日止盈、止损并从最小允许下注金额开始；自动下注不会保证正收益，倍投同样存在风险。

## 今日观影券（v2.0.1 修复）

不再按照本地下注记录或近期开奖帖子估算“今日观影券”。现在按 HDSky 站内 **当天收到的奖励短讯**计数：包含系统收件箱和自定义的「抽奖收件箱」「论坛投注」等归档文件夹，按短讯 ID 去重，只有短讯正文出现「观影随机续期奖励」才计入一次。按短讯接收日期统计自然天，不以下注日期判断。

- 最多检查每个短讯箱 10 页、每轮新短讯详情 100 条，已检查的当日短讯会缓存并去重，检查间隔默认 60 分钟。
- 详情页展示「收件箱已核实」与核验时间；网络异常、短讯页结构改变或日期无法判断时展示「待核验」，不会用 `0` 冒充已经确认的次数。
- 设置了「每日观影券次数上限」时，核验失败默认暂停本轮下注；可启用「无法获取观影券时继续执行」。独立核验任务会按检查间隔重新尝试，也可点击「立即检查观影券」。
- 读取短讯详情可能触发 HDSky 站点自身的“标记已读”，本插件不会主动删除或移动短讯；原有“评分短讯自动归档”仍由独立开关决定。
- **未进行真实账户联调**。如果站点使用了与 NexusPHP 通用页面不同的短讯 DOM / 奖励文本格式，需用脱敏后的收件箱 HTML 调整解析规则，不能把模拟测试视为真实计数验证。

## 配置页直接登录辅助站（v2.5.0）

在配置页选择天空站点后，使用「Emby 订阅登录」：

1. 填写 **主站数字 UID** 和 **主站资料中的邮箱**，点击「发送验证码」。
2. 到 HDSky **主站私信**获取六位验证码。验证码不是通过邮箱投递。
3. 保持配置页打开，填入验证码并点击「登录」。看到成功提示后，凭据已经保存并立即生效，**不需要保存、关闭或重新打开配置页**。

登录按钮只执行辅助站认证，不启动下注或观影券扫描。即使插件尚未启用，也可以先完成登录。连接使用当前选择站点的 User-Agent 和代理设置。主站 Cookie 仍由 MP 站点管理提供；辅助站登录不能替代主站 Cookie。

- 验证码发送间隔至少 60 秒，登录尝试间隔至少 5 秒；HTTP 429 按 Retry-After 冷却，无有效值时默认 5 分钟。
- 输入 UID 或邮箱变化后，应重新发送验证码。请求超时不会自动重发，可以点击「刷新登录状态」核对插件已保存的状态；该按钮只读取本地认证状态。
- 验证码提交后清空，不写入插件配置、日志或持久化数据。若未提交就使用 MP 的保存按钮，初始化时也会清除临时验证码。
- Token 保存在实例独立的数据中，不在表单回显。随后保存其他设置不会用页面里的空值覆盖新 Token。
- 老版本手动填写的 Access/Refresh Token 会自动迁移。仍可在页面下方配对填写两个 Token，点击「保存手动 Token」直接保存；手动导入的有效性由独立观影券检查核验。留空保留已有凭据。

辅助站公开登录页使用 `POST /api/user/send-code` 和 `POST /api/user/login`，字段为 `userId`、`email`、`code`；登录成功返回 `accessToken` 与 `refreshToken`。只向固定辅助站 HTTPS 地址提交，禁止自动重定向。

辅助奖励读取继续使用 `GET /api/user/emby` 与 Bearer Access Token。Access Token 有效期约 15 分钟，插件会使用 Refresh Token 自动续期，并持久化轮换后的两个 Token。Refresh Token 也失效时，在本配置页重新获取验证码登录即可。未配置辅助站凭据时，继续使用主站收件箱统计方案。

其他策略和调度设置仍由 MP 原有的保存按钮保存；认证按钮不会提交尚未保存的下注设置。

## 观影券核验修复与新设置（v2.6.0）

- **已保存 Token 的同步**：配置页接口与后台任务即使保留不同的插件对象，也会在选择核验来源和请求辅助站之前读取当前实例已保存的 Token，避免后台继续使用空凭据扫描收件箱。存在 Token 时优先使用辅助站 API；接口报错会说明原因，不会自动改用短讯结果。
- **收件日期解析**：短讯列表按消息链接所在的实际行解析，避免 NexusPHP 外层嵌套表格使第一封短讯丢失日期；日期单元格中的绝对时间提示优先于相对时间文字。确实无法确定日期时仍显示待核验。
- **无法获取观影券时继续执行**：默认关闭，修改后保存配置。开启后，未核验、核验失败或缓存过期时继续按原策略执行；已确认达到每日观影券上限时仍停止，其他次数和止盈止损限制仍有效。旧的未核实统计不会被当作今日有效计数。
- **立即检查观影券**：在「Emby 订阅登录」区域点击即可联网核验并显示今日数量或失败原因，无需等下一个检查周期。可在插件未启用时使用，会跳过缓存和自动检查的当日停止条件，但不会解除当日已确认的上限，也不会触发下注。正在下注或核验时会提示稍后再试。
- 「刷新登录状态」仅查看凭据是否保存，不能作为 Token 有效或观影券核验成功的依据。手动粘贴 Token 后先点击「保存手动 Token」，再点击「立即检查观影券」。

## 独立观影券检查（v2.1.0）

- **下注任务**：保留现有 Cron（默认每 5 分钟），只使用已核实的观影券缓存，不再顺带扫描私信收件箱。
- **核验任务**：新增独立间隔，默认每 **60 分钟**，可在配置页填写分钟数（允许 10～1440 分钟）。启用或重启后如缺少本日新鲜核验结果，会安排一次初始核验；后续由 MoviePilot 宿主管理独立定时。
- **当日达到上限**：独立检查确认当天观影券数达到配置中的「每日观影券次数上限」后，记录当日止停标记。当天后续下注 Cron、观影券 Cron 和立即下注入口均不再访问站点；「立即检查观影券」仍可手动核验。**次日本地自然天自动解除**，不需要手动重启插件。
- **检查失败或数据过期**：若配置了观影券上限，默认暂停自动下注至独立核验成功；开启「无法获取观影券时继续执行」可继续下注。未知数量仍显示待核验；已核实的达到上限标记不会因为一次暂时失败而失效。
- **不开启每日上限**：独立核验仍按配置间隔统计用于详情页，下注任务不会因为没有观影券额度限制而暂停。
- **旧配置兼容**：原配置未填写检查间隔时使用 60 分钟，不改变此前的下注 Cron 和下注策略。

注：宿主调度器每天仍可能触发已经注册的作业，但达到上限后的任务会在网络访问前直接返回。核验频率控制的是独立扫描周期，并不改变插件原有的开奖结算及短讯归档功能。

## V3 迁移说明

| 模块 | V3 处理 |
|---|---|
| 导入与平台 | 使用 V3 的 app.sdk.config、app.sdk.logging、app.sdk.network、app.sdk.plugin 和正式 SiteOper |
| 任务调度 | 去除插件自建 BackgroundScheduler；由 MoviePilot 宿主管理 Cron 和单次 DateTrigger |
| 配置 | 保留原配置字段；一次性开关保存复位失败时，不执行下注 |
| 状态隔离 | 线程锁、可变配置和运行上下文绑定插件实例；旧一代任务取消后不会因重载重新发起写入 |
| 认证与网络 | 限定 HTTPS 的 hdsky.me / www.hdsky.me；禁用请求自动重定向，避免 Cookie 意外传到非目标域 |
| 下注确认 | 必须在目标帖解析出本人的对应类型及金额，才能记录成功；返回不明确时停止本轮后续下注 |
| UI | 使用 V3 原生 VCronField；继续保留 V2 的历史统计与详情页结构 |
| 测试 | 采用 mock 检查调度、旧配置、隔离、跨域拦截及未确认下注，不发送真实网络请求 |

旧版是较大型的单文件插件，部分论坛页面和回复格式可能发生变化；V3 迁移不等于已验证站点业务结果。**遇到“下注结果未确认”时，先到论坛核对该主题是否已有自己的回复，不要立即手动重试。**
