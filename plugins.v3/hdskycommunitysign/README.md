# 天空社区客户端签到

MoviePilot V3 插件，版本 **1.2.1**。使用 HDSky 社区 Windows 客户端的每日签到接口，支持配置页直接登录、手动 Cookie、只读余额与连通性检测、定时签到、自定义重试、结果通知、每日统计和历史记录。

## 安装与使用

在 MoviePilot 的第三方插件市场加入 `https://github.com/xchenya/MoviePilot-Plugins`，刷新市场，搜索 **天空社区客户端签到** 并安装。要求 MoviePilot V3；插件版本 1.x 不表示支持 MoviePilot V1。

两种登录方式任选其一：

- **站内信登录**：在配置页填写 HDSky 数字 UID，点击“发送验证码”。收到站内信后，在同一页面输入六位验证码并点击“登录”。发送与登录均直接执行并显示结果，无需保存或重新打开配置页；发送冷却为 60 秒，验证码提交间隔至少 5 秒。
- **手动 Cookie**：展开“手动 Cookie 与连接设置”，复制已登录社区页面中 `/api/portal/session` 请求的 Cookie 请求头，粘贴后点击“验证并保存 Cookie”。UID 可留空；填写时会核对账号一致性。需要 `hdsky.supertimi.de` 社区 Cookie，通常包含 `hdsky_portal_session`，不是 `hdsky.me` 主站 Cookie。

登录操作会保存 UID 与当前连接设置，可以在插件尚未启用时完成登录；不会替你修改尚未保存的定时、通知设置。登录成功后，启用插件并点击一次“保存设置”，即可在“每日统计”页面点击“立即签到”。开启“每日定时签到”后默认每天 **08:00** 执行，Cron 时区跟随 MP；也可在 MP 服务页运行已注册的签到服务。

验证码和手动 Cookie 输入在对应提交后清空，不会放入普通配置。输入框留空会保留已保存会话；取消启用停止签到及重试。配置页与详情页不显示已保存的 Cookie 或 CSRF Token。检测会话、发送验证码、登录、手动签到都使用 MP Bearer 认证的 POST 接口，重复点击会在页面内阻止；验证码与登录失败不自动重发。旧版保存配置的一次性操作仍可兼容，启动时会先复位。

### 余额与 Cookie 检测

登录后，无需启用或执行签到即可查询余额。统计页打开及点击“刷新余额与统计”时，会通过已保存的 Cookie 只读请求 `/api/portal/session`，显示当前余额、查询时间和会话检测结果，不调用签到接口。配置页“检测 Cookie 与站点连通性”使用当前连接设置检测已保存的 Cookie；未保存的定时、通知、重试设置保持不变。

Cookie 失效提示重新登录；网络或证书错误显示检测失败，保留带时间的上次余额，不把历史余额当作检测成功。零余额正常显示 `0`，服务器未提供余额则显示“—”；切换账号不会继承旧账号余额。只读查询可同步服务器已经确认的每日签到状态，不产生签到通知。

### 签到重试

配置页可设置 **签到重试次数**（0–10 次，默认 3 次，0 关闭）和 **重试间隔**（60–86400 秒，默认 300 秒），保存后生效。首次签到不计入重试次数，手动签到与每日定时签到均适用；验证码发送和登录不参与自动重试。

网络故障、服务器临时错误、限流会安排重试。每次先查询今日状态；已签到即结束。提交结果未知时，仅重查状态，绝不再次提交同日签到。Cookie 失效或访问被明确拒绝时停止；限流等待时间取配置间隔与服务器冷却时间的较晚者。

重试由 MP 宿主服务每 30 秒检查一次到期计划，实际开始可能比设置间隔晚最多约 30 秒。次数和计划持久化，重启不重置已消耗次数；成功、停用、关闭重试、切换账号或跨越北京时间日期会结束原计划。统计页显示已用次数、下次时间或次数耗尽提示。次数耗尽后可排查连接并手动签到。

## 每日统计

- 状态页显示当前登录账号的今日签到状态、今日奖励、独立查询的当前余额，以及近 30 天已签到天数和已知奖励合计；可切换近 7 天或近 30 天明细。
- 按 HDSky UID 和北京时间日期归档，同账号同日只累计一次。`success`、`already` 和 `confirmed` 均视为已签到；失败和待确认不计入完成天数或奖励，之后只读核实成功可更新该日记录。
- 每日明细的记录时间固定为首次确认签到成功的时间，刷新余额、检测 Cookie、重复点击签到或重启均不会改变；首次通过只读查询发现已签到时，以首次确认时间记录，不推测实际签到时刻。升级会从仍保留的成功历史恢复旧版被刷新覆盖的时间；缺少原始历史时无法还原真实签到时刻。
- 已确认完成不会被后续读取失败覆盖；重复查询没有奖励或余额数值时保留此前已知值。未知数值显示“—”，汇总会标注奖励未知的已签到天数，不把缺失数值当作零奖励。
- 每日聚合独立于操作历史，保留最近 90 个自然日。升级时自动从 1.0.0 保留的历史及最后回执迁移，不重复计奖；无法补回已被旧历史上限淘汰的数据。“尚无记录”不等于漏签。
- 打开统计页和“刷新余额与统计”会只读检测社区会话，不自动签到。配置页打开和 `/state` API 仍只读取本地状态；账号切换后汇总只计算当前登录账号。

## 签到行为

- 每次先查询服务器今日状态；已签到则跳过提交。
- 对未签到账号发送一次客户端签到请求，携带当前 Cookie、CSRF Token 和随机请求键。
- 仅在服务器明确返回已核实的 CSRF 过期错误时刷新会话并重试一次，复用同一请求键。
- 提交超时、服务器错误或响应无法确认时，只查询一次状态。仍无法确认就暂停该账号当天的重复提交；下次运行仍可查询并确认完成。
- 提交意图和结果持久化，重启后不会自动重放未知结果的请求。插件本地防重日期按北京时间划分，真实签到状态以服务器为准。
- HTTP 429 按 Retry-After 冷却，无有效值时默认 5 分钟；Cookie 失效需重新登录。
- 保存最近 60 条结果，详情页显示最近 30 条；可关闭通知。服务器提供数值时显示今日奖励和银元余额。
- 可选使用 MP 代理。默认直连，保留 TLS 证书验证，不跟随重定向转发凭据。

## 接口依据

来自官方 Windows 客户端 **0.8.27 / Build 67** 的调用约定。该版本为 .NET WPF 客户端。

| 用途 | 方法与路径 |
|---|---|
| 发送站内信验证码 | POST /api/portal/auth/start |
| 提交验证码 | POST /api/portal/auth/verify |
| 查询会话与今日签到状态 | GET /api/portal/session |
| 客户端签到 | POST /api/portal/daily-checkin |

接口基址：`https://hdsky.supertimi.de:8443`。

签到请求包含 `X-HDSky-Client: app`、`X-HDSky-Platform: windows`、`X-CSRF-Token` 和会话 Cookie；JSON 为 `{"requestKey":"32位十六进制随机值"}`。默认 User-Agent 使用该客户端主 API 中的 `HDSkyWindows/0.6.0-rc.1`，与安装包版本号不同。

只实现认证与每日签到，不包含兑换、游戏或其它社区操作。

## 验证与更新

后端离线回归使用真实 CookieJar、APScheduler CronTrigger 和 Pydantic，模拟 HTTP 传输及 MP SDK；前端交互回归在 jsdom 中挂载实际 Vue/Vuetify 组件。覆盖协议、认证、Cookie 轮换、签到防重、CSRF、异常响应核对、重启、冷却、调度、直接登录、每日统计迁移与凭据脱敏。详见 [测试说明](../../tests/v3/hdskycommunitysign/README.md)。

用户已确认 **1.0.0 可以正常获取验证码并登录**。1.2.0 余额查询、检测与重试已完成离线回归，尚待真实 MP 宿主及账号联调。首次安装请先登录，运行 Cookie 与连通性检测，再执行一次“立即签到”核对结果。

前端源码位于 `src/`，`npm ci && npm run build` 构建到 `dist/assets-v1.2.1/`。运行时共享 MP 的 Vue/Vuetify，不发布全局基础样式。Vue 远程组件需要对应版本的独立 Release 安装包；单独更新市场索引不代表安装包已经生成。

- **1.2.1**：修复每日签到时间被查询刷新覆盖；首次确认后固定时间，升级时从现存成功历史恢复，余额仍正常更新。
- **1.2.0**：未签到也可查询余额，新增 Cookie 与站点连通性检测、自定义签到重试次数和间隔；遵守限流、重启防重与账号日期边界，结果未知只重查状态。
- **1.1.0**：配置页直接发送验证码与登录，新增冷却倒计时、结果反馈及每日统计；按账号日期汇总、兼容旧历史，重复检查不重复计奖。
- **1.0.0**：首个正式发布版本，接入客户端签到；保留 UID/站内信登录和手动 Cookie，新增每日调度、通知、历史和重复提交保护。
