# 思齐农场 V3

作者与维护：[xchenya](https://github.com/xchenya)。基于原作者 **KoWming** 的 [siqifram 1.0.3](https://github.com/KoWming/MoviePilot-Plugins/tree/main/plugins.v2/siqifram) 移植并持续修改，按上游 GPL-3.0 许可分发，保留原作来源与许可声明。

当前版本 **2.2.2**，要求 **MoviePilot V3**。保留原 Vue 配置页、农场管理页、种植/补种、收获、出售、偷菜、点赞、农场访问、成熟时间调度及 OCR/可选 AI 验证码识别。

## 配置与使用

1. 在 MoviePilot 站点管理添加思齐站点及有效 Cookie，插件优先使用站点地址和 User-Agent；也可在插件内填写独立 Cookie。
2. 首次安装默认关闭自动任务。配置页优先复用农场状态页的完整快照，兼容 2.1.2 的独立种子缓存；无当前账号缓存时由后端自动只读查询一次，旧版配置页也可正常读取。需要更新解锁状态时点击“刷新种子列表”；刷新失败保留已有列表与默认种子。成功的农场查询会更新共享快照，缓存按站点地址和 Cookie 摘要隔离；无法确认账号归属的旧快照需只读刷新后使用。
3. 先检查农场账号及数据，再按需启用自动收获、补种等功能。自动出售、偷菜、点赞和 AI 辅助默认关闭。
4. 总 Cron 默认为每四小时第 5 分钟巡检，已有自定义值保留；如需整点每四小时运行可设 `0 */4 * * *`。另按最早作物成熟时间加默认 2 分钟延迟安排收获。偷菜有独立 Cron，默认 `*/15 * * * *`（每15分钟）。日期和调度均使用 MoviePilot 配置时区。
5. OCR 使用 MoviePilot 的 OCR_HOST；AI 辅助还要求宿主启用智能助手并提供验证码工具。
6. “偷菜设置”有独立的开关、偷菜巡检 Cron、作物多选和“保存偷菜设置”按钮。仅保存偷菜设置不会改变补种种子、总 Cron 或其他配置。“允许偷取的作物”可多选，默认勾选萝卜、西红柿、玉米、茄子、蘑菇、樱桃，可只保留其中几种；全部取消则不注册偷菜任务。旧配置缺少偷菜 Cron 时自动使用每15分钟，不影响自动补种的“默认种子”。
7. “保存后运行一次偷菜”先保存本区配置，成功后立即执行一轮偷菜；即使关闭自动偷菜，也可手动运行。只执行偷菜，结果保留在本区供核对。保存失败不执行，运行结果不明时不自动重试；普通保存和打开配置页均不触发偷菜。

自动偷菜已从总巡检和成熟收获中移出。每轮独立巡检先读取最新农场状态，站点 `can_steal` 表示不可偷或明确剩余为0时跳过；随后每轮最多获取一个目标，按 `max_steal_count - steal_count_today` 限制作物数量，数量缺失或无效时不猜测为1。未找到所选成熟作物时等待下轮；成功一批不再写入全天完成标记，旧版已写入的偷菜完成标记也不阻止新的站点查询。该计数是作物个数，不代表可开启会话的次数。

“本次目标农场未找到所选范围内的成熟作物”只描述这轮返回的一个农场，不代表其他农场没有可偷作物。提示附带目标、所选作物、检查坑位以及排除原因数量。状态页再次获取目标会重新请求站点，两次结果不保证属于同一农场；不能仅凭先后两次结果判断筛选失败。自动流程和状态页手动提交共用作物及成熟判断。

每轮成功后沿用站点结束偷菜会话流程，并读取最新状态。后续是否可偷以站点响应为准；服务端若在结束会话后禁止当日继续偷取，插件会尊重该限制，不保证跨会话用满额度。结束会话失败会明确报告；写入结果不明时停止当前轮，不盲目重试。自动目标快照不会留给手动接口重放。

站点明确返回剩余可偷数量为 0，或“今日已偷过菜，明天再来吧”等当日耗尽反馈后，暂停当天偷菜巡检，改为 MoviePilot 配置时区次日 **00:00** 恢复并检查一轮，之后继续原偷菜 Cron。暂停只影响偷菜，总巡检和成熟收获照常执行。同账号保存配置或重启会保留暂停；切换账号独立判断。宿主在 0 点离线时，重新启动后补做恢复；恢复时其他农场操作占用中则等待它结束。没有匹配作物、未知额度、读取失败，以及仅 `can_steal=false` 而无耗尽依据，都不会误记为当日额度用完。状态页显示实际暂停截止时间，手动操作仍会重新核对站点状态。

偷菜巡检不执行收获/OCR、补种、出售或点赞；没有可偷作物、配额不足等正常检查仅记录结果，不每15分钟发送通知。实际偷取及异常仍受通知开关控制。操作共用互斥锁，偷菜忙时等下轮；一次性成熟任务等待当前操作完成后执行，避免漏跑。

自动和手动偷菜均按站点种子目录核对作物，无法识别、未勾选或未成熟的作物不会发起偷取。手动页面保留完整目标展示，未勾选的作物显示“未选作物”并禁用。筛选依据当前目标快照，站点尚未提供按种子条件的原子写入校验。

购买坑位及批量出售保留原页面确认。涉及站点魔力和库存变化，操作前核对账号与数量。

更新后关闭配置页，刷新 MoviePilot 网页并重新打开，标题应显示 v2.2.2；若仍显示旧版，可用 Ctrl+F5 强制刷新。前端资源按版本使用独立地址，后端兼容旧页面的种子读取入口。默认种子继续显示站点全部作物及解锁状态，种子读取失败会提示重试并保留原选择，不会伪装成只剩萝卜。忙碌提示区分数据读取、农场任务、偷菜任务和配置保存；缓存读取无需等待农场任务结束。普通保存配置仍会重建定时任务，只有明确点击“保存后运行一次偷菜”才立即执行本轮偷菜。

通知用户名优先使用农场接口的 `current_username`；接口未返回时，只识别 NexusPHP 登录栏 `info_block` 中退出链接前的本站账号，不扫描整页其他用户。缺少可靠登录信息或存在冲突时，通知显示“未识别”。更新后刷新一次农场数据或等待下一次任务，可替换旧缓存中的错误用户名；历史通知不变。

## V3 适配

- 使用当前公开的插件、配置、日志及调度 SDK；站点查询使用 SiteOper。
- API 保留原插件业务响应，所有路由声明响应模型并要求 Bearer 认证；前端复用宿主注入的 api 和 pluginId。
- 调度清理只影响当前实例，任务及手动操作互斥，停止后不继续发送后续农场请求。
- 图片代理和验证码下载限制同源并禁止自动跟随跳转；TLS 校验保持启用。
- 读取失败可以重试；写请求不自动重试。超时、异常 HTTP 或格式不明时停止本轮操作，提示刷新核对，避免直接重发购买或出售。
- 保留站点动作的附加响应字段，过滤 Vuetify/MDI 基础样式，前端构建产物随插件提供。

市场索引的 release=true 用于本仓库要求的 Vue 资源打包，不表示完成真实联调。当前仅完成离线 Mock、接口及构建验证，尚未在 MoviePilot 宿主或真实思齐站点验证功能、扣费及验证码识别。

前端：在本目录运行 npm ci，再运行 npm run build:web；在仓库根运行 node --test tests/v3/siqifram/test_frontend.mjs。

构建后运行 python .github/scripts/check_federation_css.py 和 python .github/scripts/check_plugin_versions.py package.json package.v2.json package.v3.json。

前端开发依赖保持上游锁文件版本。离线测试替代宿主服务并拦截站点请求，不能替代宿主安装、页面加载和真实账号验收。
